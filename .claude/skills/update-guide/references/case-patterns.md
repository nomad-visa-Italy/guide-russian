# Regex-паттерны для поиска личных кейсов DN-визы

Паттерны для обнаружения сообщений, где человек описывает личный опыт подачи/получения визы DN, ВНЖ DN, nulla osta или прохождения квестуры. Используются на шаге 2 (поиск кейсов) обоих скилов: update-guide и extract-sparse-data.

Все паттерны — case-insensitive, Unicode.

## Получение визы / одобрение / отказ

```
получил[аи]?\s+визу
визу\s+(дали|получил[аи]?|одобрил[иа])
одобрил[иа]
отказал[иа]
дали\s+визу
визу\s+дали
получила\s+визу
получил\s+визу
мне\s+(одобрили|отказали|выдали|дали)
нам\s+(одобрили|отказали|выдали|дали).{0,30}(визу|пермессо|внж)
(выдали|одобрили)\s+(визу|пермессо|внж)
visa\s+(approved|rejected|denied|received)
```

## ВНЖ / Permesso di soggiorno

```
получил[аи]?\s+пермессо
внж\s+(получил[аи]?|дали)
пермессо\s+(получил[аи]?|дали|выдали)
permesso\s+di\s+soggiorno\s+(получил|дали|выдали)
permesso\s+(получил|дали|выдали)
```

## Nulla osta

```
nulla\s+osta\s+получ
нулла\s+оста\s+получ
нулла-оста\s+получ
nulla\s+osta\s+дали
```

## Подача документов

```
подал[аи]?\s+документы
подавал[сяась]+
подал[сяась]+
делал[аи]?\s+(визу|permesso|nulla)
оформлял[аи]?\s+(визу|permesso|nulla)
```

## Квестура

```
квестур[аые].{0,50}(получил|подал|приш[её]л|визит)
(получил|подал).{0,50}квестур[аые]
```

## Консульство

```
консульств[оае].{0,80}(подал|получил|одобрил|отказал|визу)
(подал|получил|одобрил|отказал).{0,80}консульств[оае]
интервью\s+в\s+консульстве
собеседование\s+в\s+консульстве
```

## Рассказ о личном опыте

```
моя\s+история
делюсь\s+опытом
расскажу\s+как
у\s+меня\s+получилось
прошёл\s+(через|процесс|визу|интервью)
прошла\s+(через|процесс|визу|интервью)
после\s+(получения|одобрения)\s+(визы|пермессо)
в\s+итоге\s+(получил[аи]?|одобрил[иа]|отказал[иа])
итого\s+(получил[аи]?|одобрил[иа])
в\s+конце\s+концов\s+(получил[аи]?|одобрил[иа])
```

## Даты + действие (таймлайн)

```
подал[аи]?\s+\d+\s*(января|февраля|марта|апреля|мая|июня|июля|августа|сентября|октября|ноября|декабря)
\d+\s*(января|февраля|марта|апреля|мая|июня|июля|августа|сентября|октября|ноября|декабря).{0,30}(подал|получил|одобрил|отказал)
```

## DN-специфичные

```
dn.{0,20}(получил|подал|одобрили|отказали|дали)
digital\s+nomad.{0,30}(получил|подал|одобрили|отказали|визу)
lavoratore\s+da\s+remoto.{0,30}(получил|подал|одобрили|отказали)
```
