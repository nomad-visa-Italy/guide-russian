# Виза цифрового кочевника в Италии: Полный гайд

Подробное руководство по получению визы цифрового кочевника (Digital Nomad Visa / Nomade Digitale) в Италии для граждан стран, не входящих в ЕС.

## О гайде

Этот гайд создан на основе:
- **Официальных источников**: законодательство Италии, сайты консульств, визовых центров и государственных ведомств
- **Основного DN-сообщества**: дамп Telegram-чата [Digital nomad Italy](https://t.me/nomadvisaitaly) (~8 800 сообщений, 2023–2026)
- **Смежных сообществ**: Telegram-чаты [emigrantista_answers](https://t.me/emigrantista_answers) (~1 700 сообщений), [immigrazia_IT](https://t.me/immigrazia_IT) (~6 700 сообщений), [rutoitaly](https://t.me/rutoitaly) (~500 сообщений), [rutoitalychat](https://t.me/rutoitalychat) (~103 000 сообщений, из которых отобраны DN-релевантные)
- **Личного опыта**: канал [@ne_putai](https://t.me/ne_putai/3563) — детальный кейс получения визы через Москву (2025–2026)

## Система маркировки

Каждое утверждение или блок текста в гайде имеет маркировку надёжности:

| Маркер | Значение | Описание |
|--------|----------|----------|
| 🟢 | **Официально** | Из законодательства, сайтов консульств, integrazionemigranti.gov.it, Gazzetta Ufficiale |
| 🟡 | **Из опыта** | Подтверждено реальными кейсами из чата или канала, но не закреплено официально |
| 🔴 | **Спорно** | Противоречивая информация, разные кейсы показывают разные результаты |

После маркера указывается **источник** (ссылка) и **дата** информации, если известна.

**Формат ссылок на источники:**
- `[VMS Москва]` — сайт визового центра [italy-vms.ru](https://italy-vms.ru/)
- `[Чат #1234]` — сообщение в Telegram-чате [Digital nomad Italy](https://t.me/nomadvisaitaly) (основной DN-чат)
- `[emigrantista #1234]` — сообщение в чате [emigrantista_answers](https://t.me/emigrantista_answers)
- `[immigrazia_IT #1234]` — сообщение в чате [immigrazia_IT](https://t.me/immigrazia_IT)
- `[rutoitaly #1234]` — сообщение в чате [rutoitaly](https://t.me/rutoitaly)
- `[rutoitalychat #1234]` — сообщение в чате [rutoitalychat](https://t.me/rutoitalychat)
- `[@ne_putai/1234]` — пост в канале @ne_putai
- `[Консульство Москва]` — сайт консульства [consmosca.esteri.it](https://consmosca.esteri.it/)
- `[Gazzetta Ufficiale]` — Официальный вестник Италии

## Дисклеймер

> **Внимание!** Этот гайд носит информационный характер и не является юридической консультацией. Процедуры и требования могут меняться. Всегда проверяйте актуальную информацию на официальных сайтах консульств и визовых центров перед подачей документов. Авторы не несут ответственности за последствия использования данной информации.

> Информация в гайде актуальна по состоянию на **февраль 2026 года**. Италия славится тем, что правила могут различаться между консульствами, визовыми центрами и квестурами. Один и тот же вопрос может решаться по-разному в разных городах.

## Как пользоваться гайдом

1. Начните с **[Обзора](01-overview.md)**, чтобы понять общий процесс
2. Проверьте, подходите ли вы, в разделе **[Кто может подаваться](02-eligibility.md)**
3. Определите свой тип (ИП или найм) и изучите нужный раздел документов
4. Следуйте разделу **[Подготовка документов](05-preparation.md)** — там описан оптимальный порядок действий
5. Выберите консульство в разделе **[Консульства](06-consulates.md)**
6. После получения визы — раздел **[После приезда](08-after-arrival.md)**

## Обновления

Гайд поддерживается в актуальном состоянии. При обновлении:
- Новая информация добавляется с указанием даты
- Устаревшая информация помечается, но не удаляется (для истории)
- Конфликтующие данные фиксируются с обоими вариантами
